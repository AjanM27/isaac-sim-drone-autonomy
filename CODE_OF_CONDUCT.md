# Code of conduct

This project is committed to a respectful, inclusive and harassment-free
community for everyone, regardless of experience, identity or background.

## Expected behaviour

- Be considerate, constructive and technically specific.
- Critique ideas and results without attacking people.
- Respect privacy and do not publish credentials, personal information or
  unsafe real-flight instructions.
- Make safety limitations explicit when discussing physical vehicles.
- Accept correction gracefully and help keep discussions focused.

Harassment, discrimination, threats, sexualized attention, deliberate
intimidation, doxxing and sustained disruptive behaviour are not acceptable.

## Scope and enforcement

This policy applies in repository issues, pull requests, discussions and other
spaces where someone represents this project. Maintainers may edit or remove
content, close contributions, issue warnings, or temporarily/permanently ban
participants when necessary to protect the community.

Report conduct concerns privately to the repository owner through their GitHub
profile. Security vulnerabilities should use the private process described in
[SECURITY.md](SECURITY.md). Reports will be reviewed as promptly and
confidentially as practical.
